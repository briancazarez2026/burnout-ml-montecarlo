# Burnout Risk Levels in Software Engineering with Machine Learning

Data and code accompanying the article *"Burnout Risk Levels in Software Engineering with Machine Learning"* (submitted to *Current Psychology*).

## Contents

| File | Description |
|---|---|
| `simulated_data.csv` | Simulated dataset: 6,000 synthetic cases generated by parametric Monte Carlo simulation (multivariate normal distribution, seed 42) from the means and covariance matrix of 2,500 real questionnaire responses. |
| `analysis.py` | Python script that reproduces all statistics and figures reported in the article and documents the simulation procedure. |
| `requirements.txt` | Python packages needed to run the script. |

**Important:** the dataset contains **no records of real participants**. It reproduces the means, variances and covariances of the real responses, but not their higher-order features (by construction, relationships are linear and distributions approximately normal). The `Country` and `Age` columns are random labels that are not used in any analysis. The original responses are not public because they contain sensitive mental health information; they are available from the corresponding author upon reasonable request.

## Variables

- `Item1`–`Item22`: questionnaire items (4-point frequency scale, 1–4).
- `Long Working Hours`, `Role Misalignment`, `Work Overload`, `Workplace Harassment`, `Employee Turnover`, `G_Anxiety_Disorder`, `Depression`: psychosocial factor scores (predictors).
- `Burnout`: burnout score (sum of the seven factor scores).
- `Country`, `Age`: random labels (not analyzed).

## How to reproduce the results

```bash
pip install -r requirements.txt
python analysis.py simulated_data.csv output_folder
```

The script prints all statistics, saves them in `output_folder/results.json`, and creates Figs. 2–4 and S1–S3.
